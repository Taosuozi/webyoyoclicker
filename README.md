# 🪀 悠悠球比赛评分系统

一个专为悠悠球比赛设计的实时在线评分系统，集成YouTube视频播放和键盘快速评分功能。

## ✨ 系统特性

### 🎬 视频播放
- **YouTube集成**：支持任意YouTube视频链接播放
- **全屏显示**：1400×788像素大尺寸视频框架
- **自适应布局**：支持桌面、平板、手机等不同设备

### ⌨️ 键盘评分
- **数字键1-5**：分别对应+1至+5分的加分操作
- **数字键0**：减1分操作
- **R键**：快速重置分数（保持视频状态）
- **实时响应**：按键即时生效，无延迟

### 🎨 视觉反馈
- **背景闪烁**：按键时整个页面背景短暂变色（300ms）
- **视频数字显示**：在视频左上角显示评分数字和颜色
- **分数统计**：左右两侧实时显示总加分和总减分
- **页面标题更新**：浏览器标题栏实时显示当前总分

## 🚀 快速开始

### 1. 启动服务器
```bash
python -m http.server 8080
```

### 2. 打开浏览器
访问：`http://localhost:8080`

### 3. 加载视频
- 在输入框中粘贴YouTube视频链接
- 点击"加载视频"按钮
- 视频成功加载后，输入框会自动隐藏

### 4. 开始评分
使用数字键0-5进行实时评分操作

## 📋 详细使用方法

### 🎥 视频操作

#### 支持的YouTube链接格式
- 标准链接：`https://www.youtube.com/watch?v=VIDEO_ID`
- 短链接：`https://youtu.be/VIDEO_ID`
- 嵌入链接：`https://www.youtube.com/embed/VIDEO_ID`
- 移动链接：`https://m.youtube.com/watch?v=VIDEO_ID`

#### 视频控制
- **播放/暂停**：空格键或点击播放按钮
- **音量调节**：方向键上下或鼠标滚轮
- **进度控制**：方向键左右或拖拽进度条
- **全屏切换**：F键或双击视频
- **静音切换**：M键

### ⌨️ 评分操作

#### 加分操作（数字键1-5）
| 按键 | 分数 | 背景颜色 | 视频数字颜色 | 字体大小 |
|------|------|----------|--------------|----------|
| 1 | +1分 | 绿色 | 绿色 | 3.0em |
| 2 | +2分 | 蓝色 | 蓝色 | 3.3em |
| 3 | +3分 | 橙色 | 橙色 | 3.6em |
| 4 | +4分 | 紫色 | 紫色 | 3.9em |
| 5 | +5分 | 紫色 | 紫色 | 4.2em |

#### 减分操作（数字键0）
| 按键 | 分数 | 背景颜色 | 视频数字颜色 | 字体大小 |
|------|------|----------|--------------|----------|
| 0 | -1分 | 红色 | 红色 | 3.0em |

#### 重置操作
- **R键**：快速重置分数为0，保持视频播放状态
- **重置按钮**：完全重置系统，清空视频需重新输入链接

### 📊 分数显示

#### 位置布局
- **左侧**：总加分显示（绿色+号）
- **中间**：YouTube视频播放区域
- **右侧**：总减分显示（红色-号）

#### 数字显示规则
- **总加分**：累计所有正分操作的总和
- **总减分**：累计所有减分操作的绝对值
- **净得分**：总加分 - 总减分（显示在页面标题）

## 🎯 评分策略建议

### 🏆 比赛评分标准
- **+1分**：基础技巧完成
- **+2分**：技巧熟练度较好
- **+3分**：技巧执行优秀
- **+4分**：技巧完美执行
- **+5分**：超高难度技巧或创新动作
- **-1分**：失误、掉球或技巧失败

### ⏱️ 实时评分技巧
1. **预判按键**：根据选手动作提前准备按键
2. **快速连击**：支持快速连续按键操作
3. **即时纠错**：发现误操作可立即用相应操作抵消
4. **节奏把控**：跟随音乐节拍进行评分

## ⚠️ 注意事项

### 🔴 使用限制
1. **网络要求**：需要稳定的互联网连接播放YouTube视频
2. **浏览器设置**：部分浏览器可能需要允许自动播放
3. **键盘焦点**：确保页面获得键盘焦点才能响应按键
4. **视频限制**：某些YouTube视频可能限制嵌入播放

### 💡 最佳实践
1. **全屏使用**：推荐在大屏幕上全屏使用以获得最佳体验
2. **键盘操作**：使用数字键区的数字键效果更佳
3. **网络优化**：确保网络稳定避免视频卡顿影响评分
4. **数据备份**：重要比赛建议记录分数变化过程

### 🐛 故障排除
- **按键无响应**：点击页面任意位置获得焦点
- **视频无法播放**：检查网络连接或更换视频链接
- **背景不闪烁**：刷新页面重新加载样式文件
- **分数显示错误**：使用R键或重置按钮重新开始
