# 🪀 悠悠球比赛评分系统

一个专为悠悠球比赛设计的实时在线评分系统，集成YouTube视频播放和键盘快速评分功能。

## ✨ 系统特性

### 🎬 视频播放
- **YouTube集成**：支持任意YouTube视频链接播放
- **全屏显示**：1400×788像素大尺寸视频框架
- **自适应布局**：支持桌面、平板、手机等不同设备

### ⌨️ 键盘评分
- **数字键1-5**：分别对应+1至+5分的加分操作
- **数字键0**：减1分操作
- **R键**：快速重置分数（保持视频状态）
- **实时响应**：按键即时生效，无延迟

### 🎨 视觉反馈
- **背景闪烁**：按键时整个页面背景短暂变色（300ms）
- **视频数字显示**：在视频左上角显示评分数字和颜色
- **分数统计**：左右两侧实时显示总加分和总减分
- **页面标题更新**：浏览器标题栏实时显示当前总分

## 🚀 快速开始

### 1. 启动服务器
```bash
python -m http.server 8080
```

### 2. 打开浏览器
访问：`http://localhost:8080`

### 3. 加载视频
- 在输入框中粘贴YouTube视频链接
- 点击"加载视频"按钮
- 视频成功加载后，输入框会自动隐藏

### 4. 开始评分
使用数字键0-5进行实时评分操作
